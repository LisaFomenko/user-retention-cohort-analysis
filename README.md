# Когортний аналіз та оцінка Retention Rate (SQL & Google Sheets)

## Опис проєкту
Оцінка утримання користувачів (Retention Rate) методами Google Sheets та SQL на основі когортного аналізу (Cohort Analysis)

Проєкт реалізовано у два етапи: вивантаження та чищення даних за допомогою SQL (PostgreSQL) та фінальна аналітична візуалізація в Google Sheets.

---

## Виконані завдання

### Етап 1: Екстракція та очищення даних в SQL
* **Стандартизація «брудних» дат:** Оскільки історичні дати реєстрації (`signup_datetime`) та подій (`event_datetime`) зберігалися у текстовому форматі з різними розділювачами (`.`, `/`, `-`) та різною довжиною року, було реалізовано логіку очищення через `CASE` та регулярні вирази з подальшим приведенням до типу `timestamp` за допомогою `to_date`.
* **Фільтрація технічного шуму:** Очищено датасет від тестових подій (`test_event`), записів із відсутніми типами подій (`NULL`) та користувачів без дати реєстрації.
* **Когортизація та розрахунок стажу:** Розраховано місячний зсув (`month_offset`) для кожного кроку активності користувача відносно місяця його реєстрації.
* **Фінальна агрегація:** Сформовано оптимізований скрипт із використанням CTE для розрахунку загальної кількості унікальних клієнтів (`users_total`) у розрізі промо-статусу, місяця когорти та місячного зсуву. Результат експортовано у форматі CSV.

### Етап 2: Моделювання та візуалізація в Google Sheets
* **Побудова когортних матриць:** На основі агрегованих даних розгорнуто зведену таблицю (`Pivot Table`) для відображення динаміки кількості активних користувачів за місяцями.
* **Розрахунок матриці Retention Rate:** Створено вторинну трикутну матрицю для автоматичного обчислення відсотка утримання клієнтів на кожному етапі «життя» когорти відносно базового місяця (offset 0 = 100%).
* **Умовне форматування:** Застосовано градієнтну заливку матриці для швидкої візуальної оцінки точок найбільшого відтоку (churn rate).
* **Інтерактивність:** Інтегровано динамічний зріз (`Slicer`) за маркером промо-залучення, що дозволяє миттєво перебудовувати обидві когортні таблиці для порівняння Organic та Promo трафіку.
